# Fundamentos de Desenvolvimento com Java

Repositório destinado aos exercícios, práticas e projetos desenvolvidos
durante a disciplina de Fundamentos de Desenvolvimento com Java no curso
de Análise e Desenvolvimento de Sistemas.

## 📚 Conteúdos estudados

- Fundamentos de Java
- Variáveis e tipos de dados
- Estruturas condicionais
- Estruturas de repetição
- Métodos
- Classes e objetos
- Programação Orientada a Objetos
- Encapsulamento
- Sobrecarga de métodos
- Cálculo de médias e regras de negócio

## 📁 Estrutura

### `FundamentosJava`
Exercícios relacionados aos fundamentos da linguagem Java.

### `fundamentopoo`
Exercícios relacionados à Programação Orientada a Objetos.

### `TP2`
Atividades e trabalhos práticos desenvolvidos durante a disciplina.
